# StudentHub Portal

## Practical 1

### Aim
To plan and create the basic structure, sitemap and wireframes of the StudentHub Portal before starting the main development.

### About Project
StudentHub is a student portal website. It helps students to access their academic information such as attendance, results, fees details, profile and timetable.

### Pages

1. Home
2. Register
3. Login
4. Dashboard
5. Profile
6. Attendance
7. Results
8. Fees Details
9. Time Table
10. About Us
11. Contact Us

### User Role

The main user of this website is a Student.

The student can:
- Register an account
- Login to the portal
- Access the dashboard
- View profile
- Check attendance
- Check results
- Check fees details
- View timetable

### Wireframes

Low-fidelity wireframes are created to plan the basic layout of the StudentHub pages before coding.

### Navigation

The website starts from the Home page.

From Home, the user can go to:
- About Us
- Contact Us
- Login
- Register

After successful login, the user goes to the Dashboard.

From the Dashboard, the user can access:
- Profile
- Attendance
- Results
- Fees Details
- Time Table

### GitHub
